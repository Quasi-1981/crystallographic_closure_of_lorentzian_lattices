# Crystallographic Closure of Integral Lorentzian Lattices and the Rank at Which It Ends

**Vladimir Sobol** · ORCID [0009-0006-9829-7931](https://orcid.org/0009-0006-9829-7931) · Independent Researcher

A finite-order integral isometry of **any** integral lattice of signature `(3,1)` has order in
`{1, 2, 3, 4, 6}` — the familiar three-dimensional crystallographic restriction. The paper proves
this by reducing the Lorentzian question to the definite one: such an isometry always fixes an
**integral** timelike vector up to sign, and its orthogonal complement is a positive definite
lattice of one rank less. The reduction is an equality of order sets, so it also says where the
crystallographic closure **ends** — at signature `(4,1)`, where orders 5, 8, 10 and 12 walk in.

The paper is `crystallographic_closure_en.md` (English, the language of record) with
`crystallographic_closure_ua.md` beside it (Ukrainian, the language it was written in).
Everything else in this repository exists so that the paper's computational statements can be
**re-run rather than believed**.

## Reproducing

```
cd src
python S1671_cryst_restriction.py
python S1743_n4_trace.py
python S1670_rank_drop.py
python S1770_reader_litgate.py
python S1771_lattice_orders.py
```

Python 3 with `sympy` and `numpy`. Each probe prints the output recorded beside it in `*_run.log`;
every log in this package was **regenerated by execution**, not edited. The typeset artefacts are
rebuilt with

```
python src/S1765_build_tex.py --md crystallographic_closure_en.md \
       --out crystallographic_closure_en.tex --title "..." --author "..." --date "..."
pdflatex crystallographic_closure_en.tex   # twice
```

That builder ends with a **glyph gate**: any character its map does not know is reported by name,
because an unmapped character does not raise an error — it disappears silently from the PDF.

The metadata files are generated from `citation.yaml`; regenerate them with the programme's
`gen_citation.py` rather than editing `CITATION.cff` or `.zenodo.json` by hand.

## Three notes, so that nothing looks like an oversight

**On what the probes can and cannot establish.** A search inside a bounded box can witness that
something exists; it can never establish that something does not. Where the paper says "does not
occur", the support is structural, not a silent search: the parity of the negative index for §3,
and the square class of the determinant for §4 — an invariant that does not depend on which
lattice is chosen inside a fixed rational representation, and therefore settles infinitely many
lattices with one number. The one place where a search genuinely fell short is named as open:
whether order 12 acts on `I_{2,2}`.

**On the one import that is no longer there.** An earlier draft took the three-dimensional
crystallographic restriction as a cited classical result. The first attribution offered for it
turned out to be **the name of a notation mistaken for a theorem**, and was withdrawn. Rather than
hunt for a replacement, the step was **derived** — it takes three lines from the integrality of the
trace. The same thing happened a second time, in §4: rather than cite the classification of
indefinite odd unimodular lattices, the lattice was diagonalised explicitly, and what the paper
prints is a matrix the reader can multiply. Scherrer and Coxeter remain historical references, not
legs of the proof.

**On what counts as two witnesses.** The paper is explicit that its claim and the three-dimensional
restriction are *not* independent confirmations of each other: the reduction sends the first to the
second, so the multiplicity is one. The same holds for the two routes to the exclusion of order
five — the signature route and the trace route share one root, integer arithmetic. They corroborate;
they do not multiply.
